# Portfolio Website — Gaadha Jayakumar

A personal portfolio website built using HTML5 and CSS3 

---

## Project Overview

A fully responsive single-page portfolio website designed to showcase my skills, projects, and contact information. The site features a Dark deep-slate and teal theme with CSS animations, hover effects, smooth scrolling, and a custom layout built entirely with HTML and CSS.

**Sections included:**
- Home 
- About 
- Projects
- Skills
- Contact

**Features used:**

**Design and UI**

- Dark deep-slate and teal theme
- Clean and minimal layout
- Google Fonts typography

**Animations**
- Hero reveal effects
- Scroll animations
- Floating background orbs
- Smooth hover transitions

**CSS Techniques**
- CSS variables
- Flexbox & Grid
- Pseudo-elements
- Glassmorphism navbar
- Custom scrollbar
- Gradient glow effects

---

## Tech Stack

- HTML5
- CSS3 (External stylesheet)
